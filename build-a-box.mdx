A **Build-a-box** offer lets customers pick their own products for a box, unlock bigger discounts as the box grows, and subscribe to it. This page covers setting up the offer in Juo. To show the box on your store, see [Build-a-box on your storefront](/build-a-box-storefront).

## Create the parent product

The box needs a virtual parent product in Shopify that acts as a container for the products customers add.

1. In Shopify, create a new product, for example "Build your box".
2. Uncheck **Track quantity** and **This product requires shipping**.
3. Save the product.

The parent product must be different from every product customers can put in the box.

## Set up the box in Juo

1. In Juo, go to **Offers → Build-a-box** and select **Add Build-a-box**.
2. Select the **parent product** you created.
3. Optionally, give the box a **Title**. Only you see it.
4. In **Discount code**, enter the code customers see at checkout.
5. Set **Discount status** to **Active** to enable quantity discounts.
6. In **Discount type**, choose **Percentage** or **Fixed amount**.
7. In **Tiers threshold type**, choose whether tiers unlock by the number of products or by the total cart value.
8. Set the **minimum number of products** needed to unlock a discount.
9. Decide whether the box discount can combine with other discounts in the same order.
10. Under **Restrict quantity to match available tiers**, decide whether customers can only check out with quantities that match a tier.
11. Select **Add** to create the box, then select **Edit** on the box to finish the setup.

## Add discount tiers

Add tiers so the discount grows as customers add more products. Base the number of tiers and their thresholds on how much your customers usually buy, and adjust them over time to raise average order value.

## Choose boxable products

Select the products customers can add to the box. You can add as many as you want. Put the same products in a Shopify collection too: the storefront uses it to display the box.

## Add free products

To include specific free products in every box, add them under **Free products**. They work as an extra reason to buy the box.

## Let customers subscribe to the box

1. Go to **Offers → Subscribe and save** and add a plan, or edit an existing one.
2. Add every product available in the box and select **Save**.

Products can belong to different subscription plans, but the box only shows the delivery frequencies that all of its products share. Make sure every product has at least one frequency in common.
