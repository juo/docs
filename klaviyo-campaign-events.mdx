Send a custom event to Klaviyo for the subscriptions you select in Juo, and use it to trigger a Klaviyo flow. Each event includes the subscription's products, details and Customer Portal links, so your email can use them.

## Set it up

1. In **Workflows**, create a new workflow with the **Admin initiated** trigger.
2. Add a **Send event to Klaviyo** action, enter an event name, for example `Reactivation Campaign`, and publish the workflow.
3. Send a test event: in **Subscriptions**, select a test subscription with your own email address and choose **Run workflow**. Klaviyo needs one event before you can use it as a flow trigger.
4. In Klaviyo, create a flow triggered by your event, add the email and set the flow live.

## Send it

In **Subscriptions**, filter and select the subscriptions you want, then choose **Run workflow**. Klaviyo sends the emails within minutes.

<Note>
  Only one published workflow can use the **Admin initiated** trigger.
</Note>

For a full example, see [Reactivation campaigns](/win-back).
