Juo has an MCP server. MCP, the Model Context Protocol, is an open standard that lets an AI assistant work with the tools your business already runs on. Once your assistant is connected to Juo, you can ask about subscribers, subscriptions, and performance in plain language, and have the assistant make changes in your store.

## What you can ask

Ask in your own words. The assistant finds the right customer, subscription, or workflow in your store and shows what it did.

| Task | Example prompt |
|---|---|
| Find a customer | "Find anna@example.com and show her active subscriptions." |
| Skip or move one order | "Skip Anna's next order." or "Move Anna's next order to November 20." |
| Change a subscription | "Pause Anna's subscription." or "Add a free sample to Anna's next order only." |
| Review performance | "Compare cancellations this month with last month." |
| Review workflows | "List my workflows and show how the cancellation flow performed last month." |
| Build a workflow | "Create a draft workflow that offers 15% off, then a pause, when a subscriber starts to cancel." |

The assistant can work with customers, subscriptions and their items and discounts, upcoming orders, products, workflows and workflow runs, and analytics. The [MCP reference](https://juo.dev/docs/mcp) lists every tool.

## Connect your assistant

You need a Juo account with access to the store you want to connect, and an assistant that supports MCP connectors. The server address is:

```text
https://mcp.juo.com/mcp
```

<Tabs>
  <Tab title="Claude">
    1. In Claude on the web or in Claude Desktop, open **Customize**, then **Connectors**.
    2. Select **+**, then **Add custom connector**.
    3. Enter the server address above and save.
    4. The first time you use the connector, Claude opens the Juo login page. Log in with your Juo account, choose the store, and grant access.

    On Team and Enterprise plans, an organization owner adds the connector under **Organization settings**, then **Connectors**.
  </Tab>
  <Tab title="Claude Code">
    Add the server from your terminal:

    ```bash
    claude mcp add --transport http juo https://mcp.juo.com/mcp
    ```

    In a Claude Code session, run `/mcp`, select `juo`, and log in with your Juo account.
  </Tab>
  <Tab title="Codex">
    Add the server, then log in. The login opens in your browser.

    ```bash
    codex mcp add juo --url https://mcp.juo.com/mcp
    codex mcp login juo
    ```
  </Tab>
  <Tab title="Cursor">
    Add Juo to `~/.cursor/mcp.json` for all projects, or to `.cursor/mcp.json` for one project:

    ```json
    {
      "mcpServers": {
        "juo": {
          "url": "https://mcp.juo.com/mcp"
        }
      }
    }
    ```

    Cursor asks you to log in before the tools become available.
  </Tab>
  <Tab title="Other assistants">
    VS Code, Windsurf, Zed, Continue, and assistants that only support local servers each have their own setup. The [MCP reference](https://juo.dev/docs/mcp) has the configuration for each.
  </Tab>
</Tabs>

Once connected, start with a question that only reads data:

> List my workflows and show which ones are published.

## Stay in control

The assistant works with your live store, so treat its actions as you would a teammate's.

- **One store per connection.** Access is limited to the store you choose at login. To work with another store, connect again and choose that store.
- **Changes are real.** Pausing, skipping, and cancelling affect real subscribers, and cancelling can email the customer. Review each action before your assistant runs it, and keep approval prompts on for anything that changes data.
- **Deleting needs extra care.** Deleting a customer or a product is permanent. Workflows are never deleted through MCP: removing one archives it, and the run history stays.
- **Workflows are saved as drafts.** The assistant asks before it publishes. Pop-ups, polls, and other customer-facing content can't be previewed through MCP, so open the draft in the [workflow editor](/workflows/workflows-overview) and check it before you publish.
- **Disconnect when you no longer need it.** Remove the Juo connector in your assistant's settings.

## Start from a guide

The [cancellation flow guide](/workflows/guides/cancellation-flow) describes the goal and the flow of a proven pattern, so it works as a brief. Share it with your assistant and ask for a draft:

> Using the cancellation flow guide, create a draft workflow in my store. Offer a discount first, then a pause.

Review the draft in the editor, adjust the offers, and publish when it matches your terms.

export const JuoMcpDemo = () => {
  const ACCENT = "#7C74FF";
  const scenes = [
    {
      prompt: "Skip anna@example.com's next order.",
      tools: ["customers-list", "subscriptions-list", "schedules-create"],
      answer: "Done. The order due Nov 12 is skipped. Her next order is now due Dec 12.",
      extra: "none",
    },
    {
      prompt: "How have cancellations trended over the last 90 days?",
      tools: ["analytics-list-metrics", "analytics-query"],
      answer: "Cancellations per week are trending down over the last 90 days.",
      extra: "chart",
    },
    {
      prompt: "Build a cancellation flow that offers 15% off, then a pause.",
      tools: ["workflows-catalog", "workflows-create"],
      answer: "Saved as a draft. Review it in the editor before you publish.",
      extra: "flow",
    },
  ];
  const [scene, setScene] = useState(0);
  const [stage, setStage] = useState(0);
  const [auto, setAuto] = useState(true);
  const [reduced, setReduced] = useState(false);

  useEffect(() => {
    if (typeof window === "undefined" || !window.matchMedia) return undefined;
    const mq = window.matchMedia("(prefers-reduced-motion: reduce)");
    setReduced(mq.matches);
    const onChange = (e) => setReduced(e.matches);
    if (mq.addEventListener) mq.addEventListener("change", onChange);
    else mq.addListener(onChange);
    return () => {
      if (mq.removeEventListener) mq.removeEventListener("change", onChange);
      else mq.removeListener(onChange);
    };
  }, []);

  const lastStage = scenes[scene].tools.length + 1;

  useEffect(() => {
    if (reduced) return undefined;
    let delay = 700;
    if (stage === 0) delay = 900;
    if (stage === lastStage) delay = 5200;
    const timer = setTimeout(() => {
      if (stage < lastStage) setStage(stage + 1);
      else if (auto) {
        setScene((scene + 1) % scenes.length);
        setStage(0);
      }
    }, delay);
    return () => clearTimeout(timer);
  }, [scene, stage, auto, reduced, lastStage]);

  const pick = (i) => {
    setScene(i);
    setStage(0);
    setAuto(false);
  };

  const fade = (on) => ({
    opacity: on ? 1 : 0,
    transform: on ? "none" : "translateY(4px)",
    transition: reduced ? "none" : "opacity .4s ease, transform .4s ease",
  });
  const mono = 'ui-monospace, SFMono-Regular, Menlo, Consolas, monospace';
  const chipBase = { display: "inline-flex", alignItems: "center", gap: 6, padding: "3px 8px", borderRadius: 6, border: "1px solid rgba(127,127,127,.3)", fontSize: 12, lineHeight: 1.4 };

  const renderScene = (s, i) => {
    const active = i === scene;
    const shown = active ? (reduced ? s.tools.length + 1 : stage) : -1;
    const answerAt = s.tools.length + 1;
    return (
      <div
        key={i}
        aria-hidden={!active}
        style={{
          gridArea: "1 / 1",
          display: "flex",
          flexDirection: "column",
          gap: 12,
          opacity: active ? 1 : 0,
          visibility: active ? "visible" : "hidden",
          transition: reduced ? "none" : "opacity .3s ease, visibility .3s",
        }}
      >
        <div style={{ ...fade(shown >= 0), alignSelf: "flex-start", maxWidth: "100%", padding: "8px 12px", borderRadius: 10, background: "rgba(127,127,127,.14)", fontSize: 14, lineHeight: 1.45 }}>
          {s.prompt}
        </div>
        <div style={{ display: "flex", flexWrap: "wrap", gap: 6, minHeight: 26 }}>
          {s.tools.map((t, j) => {
            const done = shown > j + 1;
            return (
              <span key={t} style={{ ...chipBase, ...fade(shown >= j + 1), fontFamily: mono }}>
                {done ? (
                  <svg width="12" height="12" viewBox="0 0 12 12" aria-hidden="true"><path d="M2.5 6.5l2.2 2.2L9.5 3.8" fill="none" stroke={ACCENT} strokeWidth="1.6" strokeLinecap="round" strokeLinejoin="round" /></svg>
                ) : (
                  <span className="juomcp-pulse" style={{ width: 6, height: 6, margin: 3, borderRadius: 6, background: ACCENT }} />
                )}
                {t}
              </span>
            );
          })}
        </div>
        <div style={{ ...fade(shown >= answerAt), borderLeft: "2px solid " + ACCENT, paddingLeft: 12, fontSize: 14, lineHeight: 1.5, display: "grid", gap: 10, minWidth: 0 }}>
          <div>{s.answer}</div>
          {s.extra === "chart" && (
            <svg viewBox="0 0 180 40" style={{ width: "100%", maxWidth: 220, display: "block" }} role="img" aria-label="Line chart of weekly cancellations trending down">
              <path d="M3 8 C22 6, 34 15, 54 14 S88 22, 108 24 S150 31, 177 33" fill="none" stroke={ACCENT} strokeWidth="1.6" strokeLinecap="round" />
              <circle cx="177" cy="33" r="2.6" fill={ACCENT} />
            </svg>
          )}
          {s.extra === "flow" && (
            <div style={{ display: "flex", flexWrap: "wrap", alignItems: "center", gap: 6, fontSize: 12 }}>
              {["Cancellation clicked", "Offer 15% discount", "Offer pause"].map((n, k) => (
                <React.Fragment key={n}>
                  {k > 0 && <span aria-hidden="true" style={{ opacity: 0.5 }}>→</span>}
                  <span style={{ ...chipBase }}>{n}</span>
                </React.Fragment>
              ))}
            </div>
          )}
        </div>
      </div>
    );
  };

  return (
    <div
      className="not-prose"
      role="group"
      aria-label="Example conversation between a merchant and an AI assistant connected to Juo"
      style={{ margin: "24px 0 8px", border: "1px solid rgba(127,127,127,.25)", borderRadius: 12, background: "rgba(127,127,127,.04)", overflow: "hidden", color: "inherit" }}
    >
      <style>{`
        @keyframes juomcp-pulse { 0%, 100% { opacity: .35; } 50% { opacity: 1; } }
        .juomcp-pulse { animation: juomcp-pulse 1.1s ease-in-out infinite; }
        .juomcp-pick:focus-visible { outline: 2px solid ${ACCENT}; outline-offset: 2px; border-radius: 6px; }
        @media (prefers-reduced-motion: reduce) { .juomcp-pulse { animation: none; } }
      `}</style>
      <div style={{ display: "flex", alignItems: "center", justifyContent: "space-between", padding: "10px 14px", borderBottom: "1px solid rgba(127,127,127,.2)", fontSize: 12 }}>
        <span style={{ display: "inline-flex", alignItems: "center", gap: 8, opacity: 0.7 }}>
          <span style={{ width: 6, height: 6, borderRadius: 6, background: ACCENT }} />
          Connected to Juo
        </span>
        <span style={{ display: "inline-flex", gap: 2 }}>
          {scenes.map((s, i) => (
            <button
              key={i}
              type="button"
              className="juomcp-pick"
              aria-label={"Show example " + (i + 1)}
              aria-pressed={i === scene}
              onClick={() => pick(i)}
              style={{ width: 20, height: 20, padding: 0, border: "none", background: "transparent", cursor: "pointer", display: "grid", placeItems: "center" }}
            >
              <span style={{ width: 6, height: 6, borderRadius: 6, background: i === scene ? ACCENT : "rgba(127,127,127,.45)", transition: "background .2s ease" }} />
            </button>
          ))}
        </span>
      </div>
      <div style={{ display: "grid", padding: 16 }}>{scenes.map(renderScene)}</div>
    </div>
  );
};
