A blueprint is a ready-made [workflow](/workflows/workflows-overview) built around one subscription goal, such as saving cancellations or rewarding loyal subscribers. You start from the blueprint instead of an empty workflow, complete a short list of to-dos for your store, and publish it.

## What blueprints are for

- **Launch a proven flow quickly.** Each blueprint already contains the triggers, conditions and actions the flow needs.
- **Learn how workflows are built.** Open a blueprint to see how a complete flow fits together, then change it.
- **Brief an AI agent.** The blueprint name and its recipe give an agent connected to Juo a precise starting point.

## Where to find them

Go to **Workflows** and create a new workflow. Choose a blueprint, or build the workflow manually.

## How a blueprint works

1. **Pick a blueprint.** Each one shows what it does, its tags (for example *Churn prevention* or *Klaviyo*) and the to-dos it needs.
2. **Complete the to-dos.** For example: set the discount size, choose gift products, or set up the Klaviyo email the blueprint links to.
3. **Publish.** After publishing, a blueprint behaves like any other workflow. Edit, test or unpublish it the same way.

## Limits and gotchas

- **One published workflow per trigger.** If a blueprint uses a trigger that already has a published workflow, merge the logic into that workflow or unpublish it first.
- **Klaviyo blueprints need the email.** Blueprints that start from an email link only work after you add the link to your Klaviyo email. See [Klaviyo integration](/klaviyo-integration).
