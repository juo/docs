<Info>
  This page helps you set up Juo's built-in product page widget. If you're working on a custom storefront, see [Build a custom subscription storefront](/custom-storefront).
</Info>

<Frame>
![Shopify theme editor - Juo widget installation](https://cdn.juo.io/content-uploads/Widget_installation_7c172973d3.png)
</Frame>

The subscription widget lets customers choose between a one-time purchase and a subscription on your product pages. It shows the delivery frequencies and discounts from your [subscription plans](/subscribe-and-save), updates prices when customers switch variants, and adds the right option to the cart.

## Before you start

- [Install Juo](/installing-juo).
- Create at least one [subscription plan](/subscribe-and-save) and add products to it. The widget only appears on products that belong to a plan.
- Use an Online Store 2.0 theme, such as Dawn or any theme that supports app blocks. If your theme doesn't support app blocks, or you use a page builder, see [Page builders and older themes](#page-builders-and-older-themes).

## Add the widget to product pages

<Steps>
  <Step title="Open the theme editor">
    In Shopify admin, go to **Online Store** → **Themes**. Next to your current theme, select **Customize**.

    <Frame>
      ![Shopify admin - Theme customization](https://cdn.juo.io/content-uploads/add_widget_customize_theme_572424158f.png)
    </Frame>
  </Step>
  <Step title="Open your product template">
    From the page selector at the top, choose **Products** → **Default product**. If you use more than one product template, repeat these steps for each template that shows subscription products.

    <Frame>
      <video controls className="w-full aspect-video" src="https://cdn.juo.io/content-uploads/installation_default_product_bf2a8da9ec.mp4" />
    </Frame>
  </Step>
  <Step title="Add the widget block">
    In the product information section, select **Add block**. Under **Apps**, choose the Juo subscription widget. Drag it directly above the **Add to cart** button.

    <Frame>
      <video controls className="w-full aspect-video" src="https://cdn.juo.io/content-uploads/installation_add_widget_5ab80dc16d.mp4" />
    </Frame>
  </Step>
  <Step title="Save and test">
    Select **Save**. Open a subscription product in your store, choose a subscription option and add it to the cart. The cart should show the delivery frequency next to the product.
  </Step>
</Steps>

<Note>
  If you offer subscriptions with local payment methods, such as iDEAL, Bancontact or BLIK, keep Juo's app embeds turned on under **Theme settings** → **App embeds**.
</Note>

## Customize the widget

Select the widget block in the theme editor to change its style, colors, labels, badges and subscription benefits. See [Customize widget](/subscription-widget) for every setting.

To translate the widget's labels, use Shopify's **Translate & Adapt** app. The widget's texts appear there with your product template content.

## Add the widget to other pages

You can also show the widget outside product pages, for example on your homepage. Add a product section, such as **Featured product**, choose a product and add the Juo subscription widget block to that section. The widget picks up the product from the section. Some themes handle this differently.

## Page builders and older themes

- **Zipify Pages**: follow the [Zipify integration guide](/zipify-integration).
- **Other page builders or themes without app blocks**: contact [support@juo.io](mailto:support@juo.io) and we'll help you add the widget.
- **Fully custom product pages or headless stores**: see [Build a custom subscription storefront](/custom-storefront).

## Extend the widget with code

Developers can react to the widget from theme code without changing the widget itself. The widget exposes hooks on `window.juoSubscriptionWidget.hooks`:

| Hook | Use it to |
| --- | --- |
| `onReady` | Run code once the widget has rendered. |
| `onModeChange` | React when a customer switches between one-time purchase and subscription. |
| `onSellingPlanChange` | React when a customer picks a different delivery frequency. |
| `onPriceUpdate` | Update other page elements when the displayed price changes. |
| `filterSellingPlans` | Choose which plans the widget shows for each variant, for example to hide legacy plans. |

```javascript
function withJuoWidgetHooks(callback) {
  if (window.juoSubscriptionWidget?.hooks) {
    callback(window.juoSubscriptionWidget.hooks);
  } else {
    document.addEventListener(
      "juo-subscription-widget:hooks:ready",
      () => callback(window.juoSubscriptionWidget.hooks),
      { once: true }
    );
  }
}

withJuoWidgetHooks(({ filterSellingPlans }) => {
  // Hide subscription options on variants that are out of stock.
  filterSellingPlans((plans, variant) => (variant.available ? plans : []));
});
```

Each hook returns a function that removes it. Errors in your hooks are logged to the console and never break the widget.

<Tip>
  Need the full hooks reference, for example to show a price per day? Contact [support@juo.io](mailto:support@juo.io).
</Tip>

## Troubleshooting

<AccordionGroup>
  <Accordion title="The widget doesn't appear on a product page">
    Check that the product is in an active [subscription plan](/subscribe-and-save) and that you added the block to the template this product uses. Products can use a different template than **Default product**.
  </Accordion>

  <Accordion title="The widget doesn't update when I switch variants">
    Some themes change the selected variant without a standard change event. Ask your developer to call `window.juoSubscriptionWidget.refresh()` after the theme switches variants.
  </Accordion>

  <Accordion title="Local payment methods don't show at checkout">
    **Buy it now** and express checkout buttons skip the cart, where Juo routes subscriptions to local payment methods. Hide these buttons on subscription products and check that Juo's app embeds are turned on.
  </Accordion>

  <Accordion title="Old or imported plans show in the widget">
    Remove those products from the plan in Juo, or hide the plans with the `filterSellingPlans` hook.
  </Accordion>
</AccordionGroup>
